# Why Coding Matters to Artists and Designers

## Introduction

Multimedia entertainment combines creative practice, digital technology, and audience experience. As postgraduate students in innovative multimedia entertainment, we must not only imagine compelling ideas but also understand how they can be realised. Coding can initially seem distant from artistic practice, yet it is increasingly important in interactive media. It is not simply a production skill: it provides creative agency, enables new forms of expression, supports interdisciplinary collaboration, and develops critical literacy. Drawing on my observations of interactive theme-park attractions and game-development teams, this essay argues that a working knowledge of code helps artists and designers become more independent, informed, and thoughtful creators.

## Coding as Creative Agency

Digital tools evolve rapidly. New game engines, creative software, and interactive devices can tempt artists and designers to treat technology as a black box. We select presets, adjust sliders, and work within systems designed by others. Although these tools are useful, relying entirely on them can restrict creative choices to what their developers have anticipated.

Coding changes this relationship. When an artist can write a script, develop a shader, or design interaction logic, the computer becomes a flexible creative material rather than a fixed instrument. The practitioner is no longer only a software user but can also adapt or extend it. Reas and Fry (2014) argue that programming gives visual artists new ways to construct images, processes, and systems. Coding therefore offers creative agency: it gives makers greater control over both process and outcome.

This does not mean that every artist must become a professional software engineer. However, basic coding knowledge helps creative practitioners recognise the possibilities and limits of digital tools, allowing more intentional decisions.

## Coding as a New Expressive Medium

Coding is not merely a more efficient way to produce existing forms. It enables expression based on rules, behaviour, change, and participation. Generative art, procedural animation, responsive visual systems, and interactive installations rely on code to evolve in real time. Shiffman (2021) shows how creative coding can model movement, randomness, and natural systems in ways that are difficult to achieve through static design methods alone.

My visits to theme-park attractions made this clear. Some of the most memorable environments reacted to visitors: projections responded to movement, sounds changed as groups entered a space, or scenes developed differently according to audience choices. Their appeal was not only visual quality but the sense that the environment responded to the audience. Static graphics software can create visual assets, but code produces the responsive behaviour that makes such experiences interactive.

Coding can therefore become an expressive medium in its own right. It allows artists to create systems rather than only images, and experiences rather than only objects. In multimedia entertainment, this ability can help practitioners develop ideas beyond the limits of off-the-shelf tools.

## Coding as a Bridge for Collaboration

Coding can also improve collaboration in interdisciplinary teams. In game development, Technical Artists often work between art and engineering, translating artistic goals into workable solutions and communicating technical constraints back to creative teams. This role suggests that connecting creative and technical concerns is an important industry need.

However, Technical Artists are not a reason for other creatives to avoid coding. They can solve implementation and communication problems, but designers still need enough technical understanding to make informed decisions early in a project. A designer with no awareness of technical feasibility may propose an interaction requiring more time, equipment, or processing power than a project can support. If this is discovered only after presentation to clients or inclusion in a schedule, revision can be expensive. With basic coding knowledge, a designer can consider constraints while developing the concept. The discussion with engineers can move from “Can this be made?” to “What is the most effective way to make it?” This shared understanding reduces misunderstanding and can improve the final outcome.

The same principle applies to mobile applications, web experiences, immersive exhibitions, and AR installations. Creative practitioners need not implement every feature themselves, but understanding software logic helps them communicate more effectively with those who do.

## Coding as Critical Literacy

Finally, coding encourages critical awareness of the technologies shaping contemporary media. Digital tools are not neutral: their interfaces, algorithms, and defaults reflect assumptions about what is efficient, valuable, or possible. Artists and designers who understand some of these underlying systems are better able to question how they operate and whom they serve.

Andersen and Goriunova (2017) emphasise that software is connected to culture, pleasure, and power, rather than being merely a neutral tool. Learning code can help creative practitioners question why a system behaves in a particular way, which choices it encourages, and which users or experiences it may exclude. This critical literacy is especially important as algorithms and artificial intelligence increasingly influence creative production and audience experience.

## Conclusion

Coding matters to artists and designers because it expands what they can imagine, make, and question. It provides agency beyond ready-made tools, enables interactive and responsive forms, supports collaboration, and makes the hidden systems of digital media more visible. Learning code does not replace artistic intuition with technical thinking; it combines the two. This combination equips practitioners to create multimedia experiences that are feasible, meaningful, and engaging for audiences.
